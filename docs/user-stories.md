# User Stories — MediTriage

## HU01 — Registrar información del paciente (ingresar los datos)

**Como** personal de salud,  
**quiero** ingresar los síntomas y signos vitales del paciente,  
**para** tener la información necesaria para evaluarlo.

## HU02 — Obtener prioridad (obtener la prioridad)

**Como** personal de salud,  
**quiero** obtener el nivel de prioridad del paciente,  
**para** saber qué tan urgente es su atención.

## HU03 — Ver explicación (saber por qué se dio esa prioridad)

**Como** personal de salud,  
**quiero** ver por qué se asignó la prioridad,  
**para** entender la recomendación de la IA.

## HU04 — Ver pacientes priorizados  (ver quién necesita atención primero)

**Como** personal de salud,  
**quiero** ver los pacientes ordenados por prioridad,  
**para** saber quién necesita atención primero.

## HU05 — Revisar historial (guardar el historial para poder revisarlo)

**Como** auditor clínico,  
**quiero** revisar las recomendaciones realizadas,  
**para** consultar el historial.
