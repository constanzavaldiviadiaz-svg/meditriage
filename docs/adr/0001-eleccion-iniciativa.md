
# ADR 0001 — Elección de iniciativa

Fecha: 19/08/2026
Autores: Constanza y Fernando

Contexto :Debíamos elegir una de las iniciativas propuestas para desarrollar durante el Taller de Ingeniería de Software.

Decisión: Elegimos MediTriage — Triage clínico asistido por IA

Elegimos esta iniciativa porque nos parece interesante y nos permite trabajar con ia, requisitos, seguridad y pruebas.

Consecuencias:

Positivas: 
Nos permite trabajar con inteligencia artificial.
Podemos aplicar distintos contenidos vistos en el taller.
Nos permite trabajar temas de seguridad y calidad.
Podemos dividir el proyecto en distintas funcionalidades.

Negativsas:
El uso de IA puede hacer que el proyecto sea más complejo.
Debemos considerar la seguridad de la información.
Será necesario realizar pruebas para comprobar el funcionamiento del sistema.
